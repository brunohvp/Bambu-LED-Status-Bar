Bambu LED Status Bar

Flash the firmware straight from your browser — no PlatformIO, no drivers, no command line.

Before you start

  • Use Chrome or Edge — this needs Web Serial, which Firefox and Safari don't support.
  • Plug the ESP32 in with a USB data cable (not a charge-only one).
  • Close any other program that might have the serial port open (Arduino IDE, PlatformIO's own monitor, etc).

The button above will ask you to pick the ESP32's serial port, then flash and verify the firmware. Takes under a minute.

After flashing

The board reboots and creates its own WiFi network, BambuLED-XXXX. Connect to it from your phone — a setup page should pop up on its own (or go to http://192.168.4.1) to configure your home WiFi and printer.

Full instructions, wiring diagram and source code are in the GitHub repo.
